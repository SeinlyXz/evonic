Heuristic (HMADS) and decision-model (DMSS) safety controls for agent tool execution

System Settings

HMADS only …

Every bash / python command is scored purely by the deterministic heuristic rules — the built-in guards plus the custom rules managed in the HMADS tab. No model call, no network, fully predictable, zero extra latency.

DMSS enabled Active

A provider-hosted decision model (DMSS) also evaluates each command. shadow records and compares model decisions while HMADS still decides; enforce lets the model decide when it can.

Deterministic HMADS fallback

When DMSS is enabled, the deterministic HMADS decision is always the exact fallback. If the DMSS call times out (request_timeout_ms), its circuit breaker is open, or the model returns an unusable decision (malformed, or confidence below minimum_confidence), the pipeline applies the HMADS decision instead. A command is never left undecided — and the fallback is deterministic, so identical inputs always produce identical outcomes.
